# Workforce Program Reporting Dashboard

An interactive portfolio project demonstrating an end-to-end reporting workflow for workforce development and continuing education programs.

## Live Dashboard

**[View the Interactive Workforce Program Reporting Dashboard](https://bhanuteja-ba.github.io/workforce-program-reporting-dashboard/)**

## Project Overview

This self-directed portfolio project demonstrates how participant-level workforce program data can be transformed into validated, decision-ready reporting for program managers and organizational leadership.

The project uses a synthetic dataset of **600 participant records across five workforce programs** and follows participants from enrollment through completion, credential attainment, and employment outcomes.

All participant data used in this project is fictional and was created solely for portfolio and professional-development purposes.

## Key Performance Indicators

The dashboard monitors:

- Participant enrollment
- Program completion
- Credential attainment
- Employment placement
- Attendance
- Monthly enrollment trends
- Program-level outcomes
- Funding-source outcomes
- Record freshness and data-quality exceptions

## Dashboard Features

### Overview
Provides leadership-level KPIs and program performance comparisons.

### Program Analysis
Compares enrollment, completion, credential attainment, and employment outcomes across five workforce programs.

### Trends
Analyzes monthly enrollment patterns and participant progression from enrollment to completion and employment placement.

### Attendance & Risk
Uses attendance as an early-risk indicator and identifies participants with low attendance for additional review.

### Data Quality
Identifies reporting exceptions, monitors record freshness, and demonstrates a structured validation and resolution workflow before external reporting.

### Participant Explorer
Allows users to search and filter participant-level records by program, completion status, employment status, borough, and Workforce Pell exceptions.

## Data Quality Workflow

The project models a repeatable reporting-control process:

**Identify exception → Confirm source record → Correct or document → Rerun control → Reviewer sign-off → Report**

This approach helps ensure that reporting outputs are based on validated records rather than unreviewed source data.
